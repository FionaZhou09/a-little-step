# A Little Step · 每天一小步

给 4-6 岁中英文双语孩子的英语预习/复习小岛游戏。
家长把学校课表发给 AI 生成「课程包 JSON」，导入本应用；
孩子在动森风 3D 小岛上和动物村民互动，完成课前预习（听故事学单词）
和课后复习（听音选词），全部学会后点燃篝火庆典。

## 运行

```bash
npm install
npm run dev       # → http://localhost:5173
npm run build     # 类型检查 + 生产构建到 dist/
npm run test:e2e  # 无头 Chrome 端到端回归（需本机装有 Chrome，
                  # 可用 CHROME_PATH 环境变量指定路径）
```

## 每天的家长操作（约 1 分钟）

1. 打开应用 → 右上角「⚙️ 家长」→ 点「📋 复制提示词」；
2. 把提示词 + 老师发的课表（PDF / 截图 / 拍照均可）发给 Kimi 或 ChatGPT；
3. 复制 AI 返回的 JSON；
4. 回到家长面板 → 粘贴 → 导入。孩子开玩。
   导入的课程会存在浏览器里，下次打开自动恢复。

## 孩子怎么玩

- **走动**：WASD / 方向键，或触屏左半屏虚拟摇杆；也可以直接点地面走过去
- **对话**：靠近动物村民按 E（或点 💬 大按钮）
- **预习**：村民讲故事，讲到单词会弹出单词卡（图 + 音），点 🔊 重复听
- **复习**：预习完再聊，进入「听音选词」——听单词点对应的图，答对得 ⭐
- 学会全部单词后，回中央广场参加篝火庆典 🎉

## 技术要点

- Vite + TypeScript + Three.js，纯静态，零后端
- 零素材：程序化低多边形几何体、WebAudio 合成音效、emoji 单词配图
- 单词/故事发音用浏览器内置 Web Speech API（`speechSynthesis`，en-US 慢速），
  无语音环境时静默降级；不做语音识别
- 课程包格式与校验见 `src/lesson.ts`（`LessonPack`）
